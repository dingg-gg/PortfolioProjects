# Airline Prediction
This is a Kaggle Competition that predicts airline satisfaction using given columns

## EDA
Exploratory Data Analysis was first done and revealed several observations

1. Inflight Wifi Service is bimodal, with peaks at 0 and 5
2. Personal Type of Travel has lower satisfaction rate than Business Type of Travel
3. Wifi 0 is dominant for all trip type instead of only for one type of the trip

699635 Rows of Data, Satisfaction is boolean, Class is object, Arrival delay is in float 64 while the rest is in int64.
